# marketing-automation-toolkit

A practical open-source toolkit for performance marketers —  
automating ad creative analysis, campaign reporting, and content planning workflows.

---

## 소개 (About)

마케터가 반복적으로 수행하는 업무를 자동화하기 위해 만든 오픈소스 툴킷입니다.  
광고 소재 분석, 캠페인 성과 리포트 생성, 콘텐츠 기획 템플릿 등  
실무에서 직접 검증한 워크플로우를 공개합니다.

---

## 주요 기능 (Features)

- 📊 광고 소재 성과 분석 자동화 (CTR / CPA / ROAS 기반)
- 📝 캠페인 리포트 자동 생성 (CSV → Markdown Report)
- 🎯 소구점별 A/B 테스트 분류 템플릿
- 🤖 GPT 기반 광고 카피 초안 생성 프롬프트 패키지
- 📅 콘텐츠 기획 캘린더 템플릿

---

## 사용 방법 (Usage)

1. 이 저장소를 클론합니다
2. `templates/` 폴더에서 필요한 템플릿을 선택합니다
3. `examples/` 폴더에서 샘플 입력/출력을 확인합니다
4. 자신의 캠페인 데이터에 맞게 수정하여 사용합니다

---

## 활용 사례 (Use Cases)

- 메타 / 틱톡 / 애플서치 광고 소재 효율 분석
- 월간 성과 리포트 자동화
- 소재 방향성 회의 전 데이터 정리
- 신규 캠페인 기획 시 소구점 분류
