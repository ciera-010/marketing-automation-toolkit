# 크몽 서비스 등록 입력 시트 (서비스①)

크몽 전문가센터 > 서비스 등록 화면 순서대로 복사해서 붙여넣기.

## 1. 기본 정보
- **카테고리**: 디자인 > 상세페이지 (경쟁 상품 다수 위치. 연출컷 중심이면 '제품 사진' 계열도 검토)
- **서비스 제목**: 막 찍은 폰 사진으로 브랜드 컨셉컷부터 상세페이지까지
  - 대안: 폰 사진 한 장으로 질감·AI 모델컷까지, 팔리는 이미지 제작
- **검색 키워드**: 상세페이지, 연출컷, AI모델컷, 제품사진, 질감컷, 뷰티 상세페이지, 스마트스토어 상세페이지

## 2. 가격 (패키지)
| 항목 | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 패키지명 | 이미지 6장 | 이미지 10장 | 이미지 + 상세페이지 |
| 설명 | 연출컷 5장 + 질감·디테일컷 1장, 컷별 용도 기획 | 연출컷 4 + 질감·디테일컷 2 + 모델 사용·착용컷 2 + 누끼 2(정면·측면) | 이미지 10장 + 심화 기획서 PDF + 카피 + 상세페이지 디자인 + 피그마 템플릿 |
| 가격(오픈가) | 190,000 | 320,000 | 590,000 |
| 작업일 | 3일 | 5일 | 10일 |
| 수정 횟수 | 2회 | 3회 | 3회 |

- 오픈가는 리뷰 10건 달성 시 정가(300,000 / 450,000 / 800,000)로 변경.

## 3. 서비스 설명
- 이미지: Figma `랜딩페이지` 페이지의 `크몽 상세설명 · 서비스① DARK (860px)`를 섹션 2~3개씩 잘라 PNG로 내보내 업로드
- 텍스트: 대화에서 작성한 "서비스 텍스트 소개" 본문 사용 (FAQ에 '사진 사용 기한 없음' 포함)

## 4. 메인 이미지
- Figma `크몽 썸네일` 페이지 A안(비포애프터) 652×488 PNG로 내보내기
- 추가 이미지: B안(질감·모델컷)

## 5. 요청사항 (의뢰인 준비물)
- 연출컷: 제품 사진 1장 (밝은 곳, 정면)
- 누끼: 각도별 1장 (정면·측면)
- 상세페이지: 제품 정보(성분·사이즈·가격·인증), 원하는 분위기 레퍼런스(선택)

## 6. 올리기 전 체크
- [ ] 브랜드 로고 노출 이미지: 의뢰인 포트폴리오 사용 허락 또는 로고 블러
- [ ] 카톡 캡처: 상대 정보 제거 확인
- [ ] AI 모델 표기(FAQ 포함) 확인
- [ ] 외부 연락처·외부 결제 유도 문구 없음
- [ ] 겸업 규정 확인
