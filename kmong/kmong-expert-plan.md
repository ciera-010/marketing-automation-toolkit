# 크몽 전문가 등록 기획안

> 서비스 2개: ① 사진 한 장이면 OK, 연출컷 & 상세페이지 제작 ② 광고소재 기획·제작
> 작성일: 2026-11-09 · 근거: 크몽 검색 결과(gig 가격·구성 스니펫). 크몽 페이지 원문은 이 환경에서 직접 열리지 않아, 등록 전 상위 gig 3~4개는 직접 한 번 훑어보길 권장.

## 0. 시장 조사 요약 (크몽 현황)

| 구분 | 가격대 | 대표 구성 | 시사점 |
|---|---|---|---|
| AI 연출컷 단건 | 1장 13,000원 / 4장 45,000원 / 6장 69,000원 | 수정 5회, 1~2일 | 가격 경쟁 치열. 장수로만 팔면 레드오션 |
| AI 연출컷 할인형 | 정가 100,000 → 39,000원(제품컷), 59,000원(모델컷) | "1일 이내" | 속도·할인 표기가 기본값 |
| 실사 연출 촬영 | 1컷 55,000원, 누끼 22,000원 | 제품 택배 필요 | 실사는 배송·소품 부담 → **"사진 한 장"이 이 불편을 정면으로 해결** |
| 상세페이지 디자인 단독 | 95,000 / 140,000 / 190,000원 | 기획서는 의뢰인 준비 | 기획 빠진 상품 많음 |
| 상세+촬영/AI 올인원 | 300,000 ~ 880,000원 | 기획+디자인+AI컷, 3~7일, 수정 3회 | 중간 가격대(10~20만원)가 비어 있음 |
| 광고소재 저가 | 1장 7,000원 ~ 28,000원 | 제공 이미지·텍스트로 단순 제작 | "디자인 외주" 포지션. 기획 없음 |
| 광고소재 묶음 | 5장 66,000 / 10장 121,000 / 20장 220,000원 | 1:1 사이즈 위주 | 장수 = 가치로 파는 구조 |
| 광고소재 기획 포함 | 50,000 / 80,000 / 110,000원 | 카피라이터 협업 옵션 | 기획을 "옵션"으로 붙인 수준 |
| 소재+운영 대행 | 30,000 ~ 600,000원 | 세팅·운영 포함 | 운영까지 가면 가격 급등 |

**핵심 관찰**
1. 시장이 **"싸고 빠른 장수형"** vs **"비싼 올인원"** 으로 양극화. 그 사이 **"기획이 들어간 중간 가격"** 이 약함.
2. 광고소재 쪽은 대부분 **디자이너가 파는 상품**. "어떤 타겟에게 어떤 메시지로 테스트할지"를 파는 곳은 드묾.
3. 연출컷 쪽은 **AI 툴 사용자**가 다수. 차별점이 "퀄리티/속도" 외엔 거의 없음 → **"팔리는 컷 기획"** 으로 차별화 여지.

## 1. 전문가 포지셔닝 (두 서비스 공통)

**한 줄 정의:** 광고 성과를 직접 보는 인하우스 마케터가, 클릭되고 팔리는 이미지를 기획부터 만든다.

| 근거 (신뢰요소) | 상세페이지에 쓰는 방식 |
|---|---|
| 피트니스 앱·데이팅 앱·커머스 앱 인하우스 마케터 경력 | "앱/커머스 인하우스 마케터 N년차" (회사명은 노출 범위 확인 후) |
| 퍼포먼스 분석·예산 분배·캠페인 구성 직접 수행 | "소재를 만들고, 성과(CTR·CPA)까지 직접 봅니다" |
| 광고 콘텐츠 기획·제작 / 와디즈 광고 운영 | 작업 사례 카드 |
| 키비주얼·상세페이지 사이드 프로젝트 (해외 간식, 멀티비타민 등) | 서비스 ①의 포트폴리오 |
| 브랜드가 먼저 협업 제안하는 마이크로 인플루언서 | "SNS 트렌드를 매일 만드는 쪽에 있는 사람" |

> ⚠️ 반박 포인트: "인하우스 경력"은 강점이지만 크몽 구매자(소상공인·1인 셀러)는 **경력보다 Before/After** 를 먼저 본다. 경력은 3번째 섹션 이하로 내리고, 첫 화면은 결과물로.

## 2. 서비스 ① 사진 한 장이면 OK, 연출컷 & 상세페이지

### 2-1. 기획 프레임
- **배경:** 1인 셀러/소상공인은 실사 촬영(1컷 5.5만원 + 택배 + 소품)이 부담. AI 연출컷은 싸지만 "예쁘기만 하고 안 팔리는 컷"이 많음.
- **목표:** 폰 사진 한 장으로 **"쓸 곳이 정해진"** 연출컷 + 상세페이지까지 받는 경험.
- **타겟:**
  - 1순위: 스마트스토어·쿠팡·와디즈 신규 입점 셀러 (사진 없음, 예산 적음)
  - 2순위: 기존 셀러 중 상세페이지 리뉴얼 필요한 곳 (전환율 고민)
- **가설:** 연출컷을 "무드"가 아니라 **용도(썸네일 / 상세 첫 화면 / 사용 장면 / 광고 소재)** 로 나눠 팔면 장수 경쟁에서 빠져나와 객단가를 올릴 수 있다.
- **핵심 메시지:** "택배도, 촬영도 필요 없어요. 폰 사진 한 장이면, 팔리는 컷이 나옵니다."

### 2-2. 제목·썸네일안
- 제목 A (기본): **사진 한 장이면 OK, 연출컷부터 상세페이지까지**
- 제목 B (성과형): **폰 사진 한 장으로 끝내는 연출컷·상세페이지**
- 썸네일(652×488): 좌측 "폰으로 찍은 어두운 원본" → 우측 "완성 연출컷 3종" Before/After + 큰 카피 **"사진 1장 → 연출컷 + 상세페이지"**
  - 작은 썸네일에서도 읽히게 텍스트는 12자 내외, 화살표 하나로 끝.

### 2-3. 패키지 (초안)

| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 이름 | 연출컷 스타터 | 썸네일+연출 세트 | 상세페이지 올인원 |
| 구성 | 연출컷 3장 (1무드) | 연출컷 6장 (2무드) + 대표 썸네일 1장 + 컷별 용도 가이드 | 기획(타겟·USP 정리) + 카피 + 상세페이지 8~10섹션 + 연출컷 8장 + 썸네일 |
| 가격 | 39,000원 | 89,000원 | 290,000원 |
| 작업일 | 2일 | 3일 | 7일 |
| 수정 | 2회 | 3회 | 3회 |

- **포지션 이유:** STANDARD는 시장가(1장 1.3만원 ~ 4장 4.5만원) 안에서 "입문용", PREMIUM은 올인원 최저 구간(30만원대) 바로 아래로 잡아 **기획 포함 상품 중 진입장벽 낮은 쪽**을 선점.
- **추가 옵션:** 연출컷 추가 1장 10,000원 / 모델 착용·사용컷 +20,000원 / 급행(24시간) +30% / 광고 소재 사이즈 변환(1:1, 4:5, 9:16) +15,000원 → 서비스 ②로 자연스럽게 연결.
- **오픈 전략:** 첫 리뷰 5~10건까지는 정가 대비 30% 할인 표기 + 리뷰 작성 시 연출컷 1장 추가.

### 2-4. 상세설명(랜딩) 구성

1. **훅:** "택배 보내고, 촬영 기다리고, 소품 사고… 이제 안 해도 돼요. 폰 사진 한 장이면 충분합니다."
2. **이런 분께:** 사진 없이 입점부터 해야 하는 셀러 / 촬영비가 부담되는 소량 브랜드 / 예쁜데 안 팔리는 상세페이지가 고민인 분
3. **Before / After 3세트:** 폰 원본 → 연출컷 → 상세페이지 적용 화면 (카테고리별: 식품, 뷰티, 생활용품)
4. **왜 다른가 (차별점 3개)**
   - 예쁜 컷이 아니라 **쓸 곳이 정해진 컷**: 썸네일용 / 첫 화면용 / 사용 장면용
   - 광고를 직접 돌리는 마케터라 **클릭되는 구도**를 압니다
   - 상세페이지까지 이어지는 **같은 톤**으로 제작
5. **패키지 비교표** (위 표)
6. **진행 과정:** 사진 전달 → 무드 레퍼런스 확인(시안 방향 1회 확정) → 제작 → 수정 → 원본 전달
7. **준비물:** 제품 사진 1장(필수) / 가능하면 정면·측면·라벨 근접컷 2~3장 / 원하는 분위기 레퍼런스(선택) / 상세페이지는 제품 정보(성분·사이즈·가격)
8. **주의사항 & FAQ**
9. **CTA:** "사진 한 장 보내고 무료 방향 상담 받아보세요"

### 2-5. 꼭 넣어야 할 리스크 관리 문구
> ⚠️ 반박 포인트: "사진 한 장이면 OK"는 강한 훅이지만 **기대치 리스크**가 가장 크다.
- AI는 **라벨 글자·로고·용기 형태**를 왜곡할 수 있음 → "제품 형태·라벨은 원본 기준으로 보정하며, 한 장으로 복원이 어려운 각도는 추가 사진을 요청드릴 수 있어요"
- 실제와 다른 크기·색감은 **표시광고 이슈**가 될 수 있음 → "제품 실물과 다르게 보이는 연출은 하지 않습니다"
- 사용한 AI 툴의 **상업적 이용 가능 여부**를 FAQ에 명시
- 결과물 포트폴리오 활용 동의 여부 체크

## 3. 서비스 ② 광고소재 기획·제작

### 3-1. 기획 프레임
- **배경:** 크몽 광고소재는 대부분 "주신 이미지·텍스트로 디자인"하는 장수형. 정작 셀러가 모르는 건 **무엇을 말할지(메시지)와 무엇을 테스트할지(가설)**.
- **목표:** "소재 몇 장"이 아니라 **"테스트 가능한 소재 세트"** 를 판다.
- **타겟:**
  - 1순위: 메타·인스타 광고를 직접 돌리는 소규모 브랜드/1인 셀러 (CTR은 나오는데 전환이 안 됨)
  - 2순위: 와디즈·텀블벅 펀딩 오픈 전 브랜드
  - 3순위: 앱 서비스 초기 스타트업 (인하우스 앱 마케팅 경험과 직결)
- **가설:** 소재를 **앵글(문제 해결형 / 상황 공감형 / 후기형 / 정보형)** 로 나눠 제공하면, 의뢰인이 "어떤 메시지가 먹히는지"를 학습할 수 있어 재구매가 생긴다.
- **핵심 메시지:** "예쁜 소재 말고, 테스트할 수 있는 소재를 드립니다."

### 3-2. 제목·썸네일안
- 제목 A: **광고 돌리는 마케터가 기획하는 전환 광고소재**
- 제목 B: **타겟·메시지 기획부터, 테스트하는 광고소재 세트**
- (기존 gig "퍼포먼스 마케터가 제작하는 광고소재"와 겹치지 않게 '기획/테스트'를 앞세움)
- 썸네일: 소재 3장을 나란히 두고 위에 라벨 **[문제 해결형] [상황 공감형] [후기형]** + 카피 **"앵글별로 테스트하는 광고소재"**

### 3-3. 패키지 (초안)

| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 이름 | 소재 스타터 | 앵글 테스트 세트 | 기획+숏폼 풀세트 |
| 구성 | 이미지 소재 3종 (카피 포함, 1:1·4:5) | 소재 기획서(타겟·가설·메시지 3앵글) + 이미지 6종 + 숏폼 스크립트 1편 | 기획서 + 이미지 9종 + 숏폼 영상 2편(제공 소스 편집) + 2주 후 성과 리뷰 1회 & 다음 소재 제안 |
| 가격 | 59,000원 | 149,000원 | 390,000원 |
| 작업일 | 3일 | 5일 | 7일 (+리뷰) |
| 수정 | 2회 | 2회 | 3회 |

- **포지션 이유:** 7,000원대 단건과 싸우지 않는다. 비교 대상은 "기획 포함 5~11만원" 상품이고, DELUXE에서 **기획서라는 눈에 보이는 산출물**로 가격 차이를 정당화.
- **PREMIUM의 '성과 리뷰'** 가 재구매 장치: 데이터 보고 다음 소재를 제안 → 정기 구매(월 패키지)로 전환.
- **추가 옵션:** 9:16 사이즈 변환 / 소재 추가 1종 15,000원 / 후킹 카피 10안 29,000원 / 월 정기(4주) 별도 견적.

### 3-4. 상세설명(랜딩) 구성

1. **훅:** "CTR은 나오는데 구매가 안 된다면, 디자인이 아니라 메시지 문제일 수 있어요."
2. **이런 분께:** 광고는 켰는데 뭘 바꿔야 할지 모르는 분 / 소재를 매번 감으로 만드는 분 / 펀딩·런칭 전 소재가 필요한 분
3. **소재 기획서 샘플 공개 (블러 처리)**: 타겟 → 문제 → 가설 → 핵심 메시지 → 앵글별 카피
4. **앵글별 예시:** 같은 제품을 문제 해결형 / 상황 공감형 / 후기형으로 만든 3장 비교
5. **왜 다른가:** 직접 예산 짜고 CPA 보는 인하우스 마케터 / 소재를 장수가 아니라 가설 단위로 설계 / 숏폼 스크립트까지 한 번에
6. **패키지 비교표**
7. **진행 과정:** 사전 질문지 → 기획서 확정(1차 컨펌) → 제작 → 수정 → 전달 (→ PREMIUM은 2주 후 리뷰)
8. **준비물:** 제품/서비스 소개, 브랜드 에셋(로고·폰트·컬러), 기존 광고 소재와 성과(있으면 CTR·CPA), 경쟁사 레퍼런스, 필수 표기 문구
9. **FAQ:** 광고 운영도 해주나요?(→ 운영 대행은 범위 외, 세팅 가이드는 제공) / 성과 보장되나요?(→ 보장 불가, 테스트 설계로 확률을 높이는 서비스) / 영상 촬영도 하나요?(→ 제공 소스 편집 기준)
10. **CTA:** "현재 광고 소재 보내주시면, 앵글 진단 1줄 피드백 무료로 드려요"

## 4. 두 서비스 연결 (크로스셀 구조)

```
서비스 ① 연출컷 구매 → "이 컷, 광고 소재로도 쓰실래요?" (사이즈 변환 옵션)
                    → 서비스 ② 소재 세트로 업셀
서비스 ② 소재 구매  → "상세페이지가 전환을 막고 있어요" (랜딩 진단)
                    → 서비스 ① PREMIUM 업셀
```
- 두 상세페이지 하단에 서로의 서비스를 **"함께 많이 찾는 서비스"** 로 링크.
- 포트폴리오 탭: 한 제품으로 **연출컷 → 상세페이지 → 광고소재** 까지 이어지는 케이스 1개를 대표 사례로 제작 (가상 브랜드라도 OK).

## 5. 등록 전 체크리스트

- [ ] **겸업 규정 확인** (현재 재직 중 → 취업규칙·근로계약서의 겸업 금지 조항)
- [ ] **포트폴리오 저작권/NDA**: 회사 소재는 회사명·성과 수치 공개 가능 범위 확인. 애매하면 사이드 프로젝트·가상 브랜드 작업물로 대체
- [ ] AI 툴 상업적 이용 라이선스 확인 후 FAQ에 명시
- [ ] 샘플 제작: 서비스 ① Before/After 3세트(식품·뷰티·생활), 서비스 ② 기획서 샘플 1부 + 앵글 비교 3장
- [ ] 썸네일 652×488, 작은 화면에서 카피 가독성 테스트
- [ ] 크몽 결제 수수료(구매자 측 4.5% 안내 사례 있음) 및 판매 수수료 최신 기준 확인 후 가격 확정
- [ ] 첫 리뷰 확보 플랜: 지인 셀러·협찬 브랜드 네트워크에 오픈 할인 공지

## 6. 회의용 고민 포인트 (스스로에게 반박)

1. **서비스 ①이 "AI 이미지 장수 경쟁"에 끌려 들어가지 않을까?** → STANDARD는 미끼, 수익은 DELUXE/PREMIUM. 상세 첫 화면부터 "용도 기획"을 보여줘야 함.
2. **서비스 ②의 PREMIUM '성과 리뷰'는 의뢰인이 데이터를 안 주면 무의미하다.** → 리뷰 조건(광고 관리자 스크린샷 제공)을 패키지 설명에 명시.
3. **두 서비스가 너무 다르게 보이면 전문성이 흐려진다.** → 공통 프로필 문구를 "팔리는 이미지를 기획하는 마케터"로 통일.
4. **가격이 첫 진입에 높지 않나?** → 오픈 기간만 할인 + 리뷰 10건 후 정가 복귀.
