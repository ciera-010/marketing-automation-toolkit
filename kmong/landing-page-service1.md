# 크몽 상세설명(랜딩) 기획 — 서비스 ① 사진 한 장으로 시작하는 연출컷 & 상세페이지

> 크몽 상세설명 = 모바일에서 세로로 넘겨 보는 긴 이미지 + 텍스트. 섹션마다 **목적 → 메인 카피 → 서브 카피 → 비주얼** 순으로 정리.
> 톤: 오피셜 X, "같이 고민해주는 마케터" 결. 짧은 문장, 한 화면 한 메시지.

---

## 0. 먼저 정리할 것: 누끼 다각도 vs "사진 한 장"

- PREMIUM 10장 = **연출컷 6장 + 누끼 다각도 4장** (정면 / 측면 45° / 후면 / 디테일·라벨 근접)
- ⚠️ 반박: 사진 한 장으로는 **안 보이는 면(후면·측면)을 사실대로 만들 수 없음.** AI로 지어내면 실물과 달라져 클레임·표시광고 리스크.
- 해결: 훅을 "사진 한 장이면 끝"이 아니라 **"사진 한 장으로 시작"** 으로.
  - 연출컷 = 사진 1장이면 OK
  - 누끼 다각도 = 각도별로 폰 사진만 찍어주면 OK (촬영 가이드 제공)
  - → 핵심 약속("택배·촬영 없음")은 그대로 지키면서 기대치 관리.

## 2. 섹션별 상세

### S1. Hero
- **메인 카피 A:** 폰 사진 한 장으로 시작해서, 상세페이지까지.
- **메인 카피 B:** 택배도, 촬영도 없이. 팔리는 상세페이지.
- **서브:** 택배 X · 촬영 X · 소품 X — 광고를 직접 돌리는 마케터가 기획부터 만들어 드려요.
- **비주얼:** [어두운 폰 원본] → [연출컷 3장] → [상세페이지 목업] 가로 흐름, 화살표 2개.
- **뱃지:** `기획 포함` `피그마 템플릿 제공` `오픈 기념가`

### S2. 공감 체크리스트
- **메인:** 혹시 이런 고민 있으셨나요?
- ☐ 촬영 견적 받아보고 깜짝 놀랐다
- ☐ 제품 택배 보내고, 결과물 기다리느라 오픈이 밀렸다
- ☐ 사진은 예쁜데 이상하게 안 팔린다
- ☐ 상세페이지 문구 하나 바꾸려 해도 매번 외주를 다시 맡긴다
- **비주얼:** 체크박스 UI, 하나씩 체크되는 느낌.

### S3. 관점 전환
- **메인:** 문제는 사진이 아니라, 사진이 **어디에 쓰일지** 정해지지 않은 거예요.
- **서브:** 썸네일에서 클릭되는 컷, 첫 화면에서 붙잡는 컷, 구매를 확신시키는 컷은 다 달라요.
- (System 1 로망 자극 → System 2 납득으로 넘어가는 브릿지)

### S4. Before / After
- 카테고리 3개: **식품 / 뷰티 / 생활용품**
- 각 세트: [폰 원본] → [연출컷] → [상세페이지 적용 화면]
- 캡션: "원본: 거실에서 폰으로 촬영 / 결과: 썸네일용 연출컷" 처럼 **용도를 라벨로** 달기.
- 실제 작업물 부족하면 가상 브랜드로 제작하되 "샘플 작업" 표기.

### S5. 차별점 3가지
1. **예쁜 컷이 아니라, 쓸 곳이 정해진 컷** — 모든 컷에 용도 라벨(썸네일·첫 화면·사용 장면·광고)을 붙여 드려요.
2. **클릭되는 구도를 아는 마케터** — 인하우스에서 광고 소재 만들고 CTR·CPA까지 직접 봐요.
3. **피그마 템플릿으로, 수정은 직접** — 가격·문구 바뀔 때마다 다시 맡기지 않아도 돼요. (PREMIUM)

### S6. 10장 구성 예시 (PREMIUM)
| 구분 | 장수 | 용도 |
|---|---|---|
| 썸네일 연출컷 | 1 | 검색 결과에서 클릭 |
| 키비주얼 | 1 | 상세 첫 화면 |
| 사용 장면 | 2 | "내가 쓰는 모습" 상상 |
| 무드/라이프스타일 | 2 | 브랜드 분위기 |
| 누끼 다각도 | 4 | 정면 / 측면 45° / 후면 / 라벨·디테일 |
- **비주얼:** 10칸 그리드에 용도 라벨.
- 하단 문구: "STANDARD는 연출컷 6장, PREMIUM은 누끼 다각도 4장까지 더해 10장"

### S7. 기획서 샘플 (블러)
- **메인:** 디자인 전에, 먼저 '왜 사야 하는지'를 정리해요.
- 목차 노출: 타겟 정의 → 경쟁사 3곳 비교 → USP → 섹션별 설득 흐름 → 카피
- **비주얼:** 기획서 3페이지 겹쳐 놓고 내용 블러, 목차만 선명하게.

### S8. 패키지 비교
| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 구성 | 연출컷 6장 | 상세페이지 + 첫 화면 연출컷 2장 | 심화 기획서 + 상세페이지 + 이미지 10장(연출 6 + 누끼 4) + 피그마 템플릿 |
| 정가 → 오픈가 | 300,000 → 190,000 | 400,000 → 290,000 | 800,000 → 590,000 |
| 작업일 | 3일 | 7일 | 10일 |
- PREMIUM 칸에 `가장 많이 선택` 대신 초기엔 `기획부터 맡기고 싶다면` (리뷰 없을 때 허위 인상 방지)

### S9. 진행 과정
1. 사진 전달 & 간단 질문지 → 2. 방향(무드·용도) 1회 확정 → 3. 제작 → 4. 수정 → 5. 원본 + (피그마) 전달

### S10. 준비물 & 폰 촬영 가이드
- **연출컷:** 제품 사진 1장 (밝은 곳, 정면)
- **누끼 다각도:** 각도별 1장씩 (정면·측면·후면·라벨 근접)
- **상세페이지:** 제품 정보(성분·사이즈·가격·인증), 원하는 분위기 레퍼런스(선택)
- **촬영 가이드 그림:** 자연광 창가 / 흰 벽·흰 종이 배경 / 그림자 적게 / 라벨 글자 선명하게
- 문구: "잘 찍을 필요 없어요. 밝고, 선명하기만 하면 돼요."

### S11. About
- 앱·커머스 인하우스 마케터 (피트니스·데이팅·커머스 앱)
- 광고 소재 기획·제작, 퍼포먼스 분석, 예산 운영까지 직접
- 브랜드 협업 제안을 받는 마이크로 인플루언서
- (회사명·수치는 공개 가능 범위 확인 후)

### S12. FAQ / 주의사항
- **Q. 정말 사진 한 장이면 되나요?** 연출컷은 한 장이면 돼요. 누끼 다각도는 실물과 같아야 해서 각도별 사진을 받아요.
- **Q. 제품 모양이나 라벨이 바뀌진 않나요?** 원본 기준으로 보정하고, 실물과 다르게 보이는 연출은 하지 않아요.
- **Q. 상업적으로 써도 되나요?** 네, 사용 툴의 상업적 이용 조건을 확인한 결과물만 드려요.
- **Q. 피그마 템플릿은 어떻게 쓰나요?** 무료 상업용 폰트로 제작, 수정 가이드 포함. 구매 브랜드 내에서만 사용 가능해요.
- **Q. 수정은 어디까지 되나요?** 문구·이미지 교체는 무료 수정, 구성·기획 방향 변경은 추가 비용이에요.
